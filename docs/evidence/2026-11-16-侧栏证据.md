## 观察

### 槽位（摘录）

| 槽位 | kind / scope | 当时的 occupant / keyDomain |
|---|---|---|
| `main` | keyed / root | `keyDomain: "open: any string the owner dispatches … already taken: conversation"` |
| `sidebar.panellist` | list / root | 树里没有 fade 的行 |
| `sidebar.panellist.actions` | list / root | 空 |
| `rightbar` → `rightbar.session` → `sidebar.right.pane.tab` | keyed / session | `keyDomain: "… none are taken yet"`（右栏未展开时的正常状态） |
| `sidebar.right.pane.tab.title` | keyed / session | 同上 |
| `conversation.session.header.utilities` | list / session | 空 |
| `sidebar.right.tab.menu.item` | list / session | 存在（tab 右键菜单扩展位） |

### 三方注册写法对照

| 插件 | 注册点 | 打开方式 |
|---|---|---|
| fade 0.5.1 | `sidebar.panellist`（只画图标）+ `main`（key `dsh-novel-fade`）+ `conversation.session.header.utilities`（开关） | 无（没有派发 `main` 的通道） |
| fanfic 0.1.0 | `sidebar.right.pane.tab`（key = `dsh-novel-fanfic`）+ `sidebarRightTabs.register({id, kind, priority:'extension', guide, keepMounted})` + header 按钮 | `ctx.sidebarRight.openTab(KIND)` |
| better-sidebar 0.30.1 | `sidebar.right.pane.tab` + `sidebar.right.pane.tab.title`（key = `nativeId(descriptor.id)`）+ `tabs.register(...)` | `openTab(kind, {params})` |

### 宿主 README 原文（关键句）

- “The `id` is also the key the type's body and title register under” —— body/title 的 key 是 `id`，不是 `kind`。
- “The panel takes the conversation's ground colour and content font sizes rather than a raised layer of its own: it is a column of the page, not a card over it.”
- “The panel has no header row. Its two controls … ride the kit's chrome seat at the far end of the top-right pane's tab strip.”
- “No surface without a session.” —— 没有会话就没有右栏。
